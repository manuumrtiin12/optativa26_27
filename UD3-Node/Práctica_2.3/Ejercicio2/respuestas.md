(e)La razón por la cual el programa se detiene es porque una vez que Node ha terminado de ejecutar todas las tareas que están programadas para ejecutarse se termina y si utilizas setInterval se convierte en una tarea hasta que se cancele ya que se repite ejecutando lo mismo cada segundo. Cuando usamos clearInterval se cancela esta repetición y como ya se ha ejecutado la parte del código setTimeout nada más está corriendo y por eso el programa se detiene. Sin clearInterval seguiría para siempre y aparecerían números negativos como "Restante -1 s" ,"Restante -2 s"
